## Glossary

This glossary covers the new words in Part 2. For words from Part 1, such as function, list and class, see the Part 1 course.

Array
:   A NumPy collection of numbers of one type, stored in one block. You can do arithmetic on a whole array at once.

ASCII
:   An old code that gives a number to 128 characters, such as `A` (65) and `a` (97).

Byte
:   A number from 0 to 255. Files and networks store everything as bytes.

Caesar cipher
:   A simple cipher that shifts every letter along the alphabet by a fixed number. It is a teaching cipher and is not secure.

Cipher
:   A method for scrambling text so that only someone with the key can read it.

CSV
:   Comma-separated values. A plain text file that holds a table, one row on each line.

DataFrame
:   A Pandas table with named columns.

Digest
:   The result of a hash function. Another word for a hash.

Encoding
:   The rule that turns characters into bytes and back. UTF-8 is the usual one. Encoding is not security.

Encryption
:   Scrambling data with a key so that it can be read again only with the key.

Hash
:   A short, fixed-length fingerprint calculated from data. The same data always gives the same hash, and you cannot work back from the hash to the data.

Hexadecimal
:   A way to write numbers with the digits `0` to `9` and the letters `a` to `f`. Two hexadecimal digits write one byte.

Histogram
:   A chart that shows how the values of one measure are spread out.

Immutable
:   Cannot be changed after it is made. Strings and tuples are immutable.

Integrity
:   Knowing that data has not been changed.

JSON
:   A text format for data that looks like Python dictionaries and lists. It holds data only and cannot run code.

Log
:   A record that a computer system keeps of what happened, one line for each event.

Missing value
:   A gap in the data. Pandas shows it as `NaN`.

Personal information
:   Information about a person who is identified, or who could reasonably be identified. An address or a user name can be personal information when it is combined with other data.

pip
:   The tool that installs Python packages.

Series
:   One column of a Pandas table.

Standard deviation
:   A number that shows how spread out values are around their mean.

Status code
:   The number a web server sends back to say what happened to a request. For example, 200 means success, 401 means a login failed and 404 means the page was not found.

Synthetic data
:   Data made up for a course or a test. It describes no real people or events.

UTF-8
:   The usual way to store text as bytes. It uses 1 to 4 bytes for each character.

Validation
:   Checking data before you use it.

Vectorised
:   Working on a whole array at once, without a loop in your own code.

Virtual environment
:   A private folder of packages for one project, so that projects do not clash.

Z-score
:   How many standard deviations a value is from the mean. A z-score above 3 or below -3 is unusual.
