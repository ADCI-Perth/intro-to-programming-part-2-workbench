## Contributing

This is the Workbench (website) version of Part 2 of ADCI's *Intro to Programming* micro-credential. The course content is maintained in the main course repository, `ADCI-Perth/intro-to-programming-part-2`, and converted into this lesson with `scripts/convert_from_course.py`.

### Making changes

- **Lesson content** (sections, week pages, Concepts Bridges, practice tasks, data files): change the main course repository, then run the conversion again (see the README). Editing the episodes here directly will be overwritten by the next conversion.
- **Pages written only for this site** (`index.md`, `learners/setup.md`, `learners/reference.md`, `instructors/instructor-notes.md`, `profiles/learner-profiles.md`, `config.yaml`): edit them here.

### Style

- Australian English, written for beginners: short sentences and one idea per step.
- Course code only uses ideas already taught. Where a later idea is unavoidable, tell learners to leave it as is and say which week explains it.
- Use synthetic data only. No real logs and no personal data.
- Each week must stay at 6 hours or less.

### Reporting problems

Open an issue in this repository, or contact the course team.
