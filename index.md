**Intro to Programming, Part 2: Data and Security with Python** is the second of two six-week, beginner Python micro-credentials from the Australian Data and Cyber Institute (ADCI). It is for people who have finished **Part 1**. You learn the Python skills used in both data science and cyber security: working with text, reading files and logs, checking data and files, and using NumPy, Pandas and Matplotlib to analyse data and report what you find. Each week takes **6 hours or less**, so it fits around a full-time job.

You learn from short videos, these lesson notes, and a practice task each week. You write and run all the code in **PyCharm**. Every dataset is **synthetic**: it was made for this course, and no real logs or personal information are used. The security content is defensive and analytical only: checking, detecting, hashing and reporting.

## Learning outcomes

Part 2 meets the same four outcomes as Part 1, applied to data and security problems:

- **LO 1** Analyse and solve a problem, and implement the solution in a programming language. This is practised in every week's build.
- **LO 2** Apply programming techniques: imperative and object-oriented work in Weeks 1 to 3, and vectorised and grouped operations in Weeks 4 and 5.
- **LO 3** Design and build a program to a specification. Each week's practice task has a written checklist.
- **LO 4** Evaluate which tool or method suits a problem: a loop or an array in Week 4, and which chart to draw in Week 6.

## How each week works

Each week is one episode in the menu. Open a week to see its parts: the week overview, the sections (such as 1.1, 1.2 and 1.3), the Concepts Bridge and the practice task. Every week follows the same blocks:

| Block | Time | What you do |
|---|---|---|
| Watch | 20 to 30 min | Short videos listed on the week overview |
| Read & practise | 1.5 to 2 h | The week's sections: read, run every example, do the exercises |
| Concepts Bridge | 30 min | One general idea that the Python lessons do not cover |
| Build | 2 h (3 h in Week 6) | Your portfolio item: a practice task with starter code, a model solution and tests |
| Quiz | 15 min | A short quiz, marked automatically |

Your portfolio for each week is submitted at the end of the week and marked by your tutor.
